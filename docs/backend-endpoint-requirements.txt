Backend Endpoint Requirement: Claude API Key
==============================================

Endpoint on cliff_server.py that provides a Claude API key
to Cliff app clients.

Endpoint
--------
POST /api/{secret_path}/claude/api-key

Headers (required)
------------------
X-Cliff-App-Key: {app_key}
Content-Type: application/json

Request Body
------------
{} (empty JSON object)

Response (200 OK)
-----------------
{
  "api_key": "sk-ant-api03-...",
  "expires_in": 3600
}

- api_key: A valid Anthropic API key (string, required)
- expires_in: TTL in seconds (int, optional — client defaults to 600 if missing)

Auth
----
- Same auth pattern as /deepgram/token
- Validate the X-Cliff-App-Key header (plus the secret path segment in the URL)
- Return 401 if invalid
- No device identity and no bearer token — the contract is stateless

Notes
-----
- The client caches the key in memory with the expires_in TTL
- The client re-fetches 30 seconds before expiry
- If the key is a long-lived Anthropic key (not ephemeral), set expires_in
  to something reasonable like 3600 so the client doesn't call too often
- The Cliff app calls Claude Messages API directly at
  https://api.anthropic.com/v1/messages using model claude-sonnet-4-6
